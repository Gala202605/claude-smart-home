# 场景三：看电影模式

## 用户指令示例

```
"看电影了"
"我要看电影"
"打开影院模式"
"看个电影"
```

## Claude 预期行为

### 影院模式：
1. 调暗客厅灯（亮度 10-20%）
2. 关窗帘（如果有电动窗帘）
3. 开电视/投影
4. 调音响到影院模式
5. 空调调到 26 度（避免盖毯子太热）

### 如果只说了"看电影"但没有具体影片：
Claude 会只用文字回复确认操作，不会播放电影（因为没有具体片名）

## 实现原理

这个场景展示了 Claude 的**复合指令拆解**能力：
1. 识别场景关键词 → "看电影"
2. 拆解为 4-5 个独立操作
3. 依序或并行执行
4. 汇总回复

## 进阶用法

如果配合 Plex/Jellyfin 媒体服务器集成：
```
"帮我放《流浪地球》"
```
Claude 会：
1. 执行影院场景（调暗灯、关窗帘）
2. 调用 media_player 打开电视/投影
3. 调用媒体服务播放指定影片
