# 场景一：起床模式

## 用户指令示例

```
"Hey Claude，早上了"
"起床了"
"早上好"
"今天天气怎么样"
```

## Claude 预期行为

### 如果配置了起床场景：
1. 自动打开卧室窗帘（如果有电动窗帘）
2. 逐渐调亮卧室灯（从夜灯亮度到 80%）
3. 播报今天天气和日期
4. 如果有闹钟，停止闹钟

### 如果没配置自定义场景（通用行为）：
1. 回答问候
2. 如果用户问天气 → 读取天气实体状态
3. 不做不需要的设备操作

## 实现原理

Claude 通过 system prompt 中的"场景理解"部分知道"起床"对应的操作。

如果你想让起床场景更精确，在 system prompt 中添加：

```
## 起床场景
当用户说"起床了"/"早上好"时：
1. 开卧室灯（亮度 80%，暖光）
2. 开客厅窗帘
3. 如果是工作日，再加一句今天的日程
```

## 最佳实践

- 建议用 System Prompt 明确写"场景"定义
- 第一次尝试时说清楚："Hey Claude，起床了，打开窗帘和灯"
- Claude 会学到你的习惯，后续简单的"起床了"也能执行
