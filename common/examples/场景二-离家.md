# 场景二：离家模式

## 用户指令示例

```
"我要出门了"
"去上班了"
"离家模式"
"关掉所有灯和空调"
"我走了，帮我关好家"
```

## Claude 预期行为

### 安全模式（推荐）：
1. 关所有灯（跳过冰箱、路由器等不应关的设备）
2. 关所有空调/暖气
3. 关电视/投影/音响
4. 如果有扫地机器人 → 启动清扫
5. 如果有智能门锁 → 确认门已锁（只读，不操作门锁）
6. 如果有门窗传感器 → 提醒未关的门窗

### 如果不希望 Claude 碰某些设备：
在 system prompt 中添加：

```
## 安全限制
离家模式时：
- 不要操作冰箱、路由器、鱼缸过滤器
- 不要开关门锁（只检查状态）
- 如果室外温度 > 35度，保留一个空调调到28度（宠物模式）
```

## 实现原理

Claude 会在 messages 中看到当前所有设备的状态，包括：
- 哪些灯是开着的 → 关掉
- 空调状态 → 关闭
- 电视状态 → 关闭

通过对实体 domain 和 device_class 的判断组合执行。

## 注意

- 离家模式是最容易出错的场景（误关不该关的设备）
- 建议第一次运行时，在 HA 日志里看 Claude 调用了哪些服务
- 确认无误后再正式使用
