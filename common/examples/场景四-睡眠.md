# 场景四：睡眠模式

## 用户指令示例

```
"睡觉了"
"晚安"
"我要睡了"
"睡眠模式"
"准备休息"
```

## Claude 预期行为

### 标准睡眠模式：
1. 关客厅灯
2. 关电视/音响
3. 关窗帘（如果有）
4. 卧室灯调为夜灯（亮度 5% 或关掉）
5. 空调设睡眠模式（26-27度，低风速）
6. 如果有智能门锁 → 确认门已锁

### 如果有多个卧室：
```
"睡觉了" → Claude：你说的是主卧还是次卧？
"主卧" → 只操作主卧相关设备
```

## System Prompt 配置建议

```
## 睡眠模式
当用户说"睡觉了"/"晚安"时：
1. 关闭客厅、餐厅、书房的灯
2. 关闭客厅电视
3. 卧室灯调为夜灯模式（亮度 10%）
4. 卧室空调设 26 度、睡眠模式、低风速
5. 如有窗帘，关闭卧室窗帘
6. 检查门锁状态（只检查不操作）
7. 回复"晚安，好梦"
```

## 注意

- 睡眠场景涉及隐私（卧室设备），Claude 不保存任何数据
- 对话历史只存在 HA 内存中，重启后清空
- 所有操作可随时在 HA 日志中追溯
