🪟 Windows 安装步骤 PowerShell 管理员执行

1
装 Docker Desktop
👉 浏览器打开 https://www.docker.com/products/docker-desktop/ 下载 Windows 版 → 双击安装 → 按提示重启电脑
2
启动 Home Assistant
docker run -d --name homeassistant --restart unless-stopped \ --privileged -p 8123:8123 -v /opt/ha/config:/config \ ghcr.io/home-assistant/home-assistant:stable
3
克隆项目 → 安装 Claude 组件
cd /opt/ha/config && mkdir -p custom_components git clone git@github.com:Gala202605/claude-smart-home.git /tmp/csh cp -r /tmp/csh/way1-ha-assist/custom_components/claude_conversation .
4
写 API Key → 重启
echo 'claude_conversation: api_key: "sk-ant-你的Key"' >> configuration.yaml docker restart homeassistant
5
浏览器配语音管道 → http://localhost:8123
语音转文字: Wyoming Whisper | 对话代理: Claude | 文字转语音: Edge TTS
📌 命令在 PowerShell（管理员） 中逐行执行  ·  Docker Desktop 需保持开机自启
