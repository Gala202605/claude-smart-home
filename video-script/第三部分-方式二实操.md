## 第一步：硬件组装（3:00-5:00）

**[画面]**：桌面俯拍 + 手部操作特写

**[旁白]**：很简单，三个步骤。

**[演示]**：
1. **插 SD 卡**：把烧录好系统的 SD 卡插到树莓派背面
2. **插 ReSpeaker**：对准 40 针 GPIO 排针，轻轻压到底
3. **插音箱**：音频线插到 3.5mm 口

**[特写]**：对准 GPIO 针脚
```
⚠️ 注意方向！ReSpeaker 的 USB 口和树莓派的 USB 口要朝向同一侧
```

**[画面]**：组装完成的效果
```
树莓派 + ReSpeaker 叠在一起，大概两指厚
插上电源线、音箱线
亮灯了！
```

---

## 第二步：烧录系统 + 跑脚本（5:00-9:00）

**[旁白]**：装好硬件，我们来装系统。

**[画面]**：电脑屏幕录屏
1. 下载 Raspberry Pi Imager
2. 选择 Raspberry Pi OS Lite (64-bit)
3. 选 SD 卡，写入
4. 写入前配置 SSH、WiFi

**[旁白]**：我习惯在写入时就把 WiFi 和 SSH 配好，这样插卡开机就能远程连了。

**[录屏]**：SSH 连接树莓派
```bash
ssh pi@192.168.x.x
```
然后上传配置脚本

**[画面]**：
```bash
# 从电脑传到树莓派
scp setup_respeaker.sh pi@树莓派IP:/home/pi/

# SSH 登录
ssh pi@树莓派IP
sudo ./setup_respeaker.sh
```

**[旁白]**：这个脚本会一键安装 ReSpeaker 驱动、Docker、Wyoming 语音服务。跑完之后会自动重启。

**[画面]**：等待安装过程（快放）

**[旁白]**：重启后再跑第二部分：
```bash
sudo ./setup_part2.sh
```

**[画面]**：展示安装成功的日志
```
✅ 声卡已识别
✅ Whisper 模型已下载
✅ Porcupine 唤醒词服务已启动
✅ Piper TTS 已就绪
```

## 第三步：连入 HA（9:00-11:00）

**[旁白]**：树莓派这边配置好了，现在去 HA 里把它接入。

**[录屏]**：HA 操作
1. 设置 → 语音助手 → Assist Pipeline
2. 创建新管道 → "本地语音节点"
3. 配置：

```
唤醒词：Wyoming Porcupine
  → 服务器：树莓派的 IP
  → 端口：10400

语音转文字：Wyoming Whisper
  → 服务器：树莓派的 IP
  → 端口：10300

文字转语音：Wyoming Piper
  → 服务器：树莓派的 IP
  → 端口：10200

对话代理：Claude Smart Home Assistant
```

**[旁白]**：注意对话代理还是用 HA 上的 Claude 组件，树莓派只做语音采集和合成。

## 总结（14:00-结束）

**[画面]**：两张方案对比

```
方案一（零成本）：依赖小爱音箱
```

**[旁白]**：方案一省事省钱，方案二更好玩更独立。如果你家里本来就有小爱音箱，方案一完全够用了。如果你想做一个纯属于自己的 AI 管家，方案二值得折腾。
