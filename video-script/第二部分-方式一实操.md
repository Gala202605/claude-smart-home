**时长**：10-15 分钟
**风格**：手把手、实操录屏、注意事项

## 第一步：装 Home Assistant（0:30-3:00）

**[旁白]**：Home Assistant 是整个系统的中枢，所有设备都通过它来管理。

**[录屏]**：开一个终端窗口

```bash
# 如果你有 Docker 环境（推荐）
docker run -d \
  --name homeassistant \
  --restart unless-stopped \
  --privileged \
  -p 8123:8123 \
  -v /path/to/config:/config \
  ghcr.io/home-assistant/home-assistant:stable
```

**[旁白]**：跑这个命令，HA 就装好了。浏览器打开 `http://你电脑IP:8123`，注册账号，完成初始设置。

**[特写]**：
- 提示记好 IP 地址和端口
- 如果是 Windows 用户，推荐用 Docker Desktop 跑
- 没有 Docker 的，可以下载 HA OS 虚拟机镜像

**[关键提示]**：
```
⚠️ 这台电脑需要 7x24 小时开机
  旧笔记本/NUC/群晖NAS都可以
  树莓派4B以上也行
```

---

## 第二步：接入小爱音箱（3:00-6:00）

**[旁白]**：HA 装好之后，我们来接入小爱音箱。

**[录屏]**：
1. 先装 HACS（HA 的插件商店）
```bash
# 在 HA 容器里执行，或者在宿主机上
wget -O - https://get.hacs.xyz | bash -
```
2. 重启 HA
3. 设置 → 集成 → 添加集成 → 搜索 "HACS"
4. 授权 GitHub 账号

**[旁白]**：HACS 装好后，搜索 Xiaomi Mi Auto，安装这个集成。

**[录屏]**：
1. HACS → 搜索 Xiaomi Mi Auto → 下载
2. 重启 HA
3. 设置 → 集成 → 添加集成 → Xiaomi Mi Auto
4. 弹出小米扫码登录 → 手机扫码确认
5. 选择你的小爱音箱

**[旁白]**：登录成功后，你的小爱音箱就会出现在 HA 的设备列表里。

**[特写]**：展示 HA 中小爱音箱的设备页面

---

## 第三步：安装 Claude 组件（6:00-9:00）

**[旁白]**：现在来安装最重要的部分——把 Claude 接进来。

**[录屏]**：
1. 从本项目下载 `custom_components/claude_conversation/` 文件夹
2. 复制到 HA 配置目录的 `custom_components/` 下

**[画面]**：文件结构展示
```
ha_config/
├── configuration.yaml     ← 改这个文件
├── custom_components/
│   └── claude_conversation/
│       ├── __init__.py
│       ├── manifest.json
│       └── conversation.py
```

**[旁白]**：然后在 configuration.yaml 中添加配置：

```yaml
claude_conversation:
  api_key: "sk-ant-你的API密钥"
```

**[特写]**：
- 去 console.anthropic.com 注册获取 API Key
- API Key 以 sk-ant- 开头
- 新用户有免费额度

**[旁白]**：保存文件，重启 HA。

---

## 第四步：配置语音管道（9:00-12:00）

**[旁白]**：HA 重启后，我们来配置语音管道——这是把小爱的语音转文字、发给 Claude、再把回答转语音播报出来的完整链路。

**[录屏]**：
1. 设置 → 加载项 → 加载项商店
2. 安装 "Wyoming Whisper"（语音转文字）
3. 安装 "Microsoft Edge TTS"（语音合成）
4. 等待安装完成

**[旁白]**：然后创建一个 Assist Pipeline：

**[录屏]**：
1. 设置 → 语音助手 → Assist Pipeline
2. 创建新管道，命名为 "Claude"
3. 语音转文字 → 选择 Wyoming Whisper
4. 对话代理 → 选择 "Claude Smart Home Assistant"
5. 文字转语音 → 选择 Edge TTS（中文女声）
6. 保存

**[旁白]**：关键一步——把 Xiaomi Mi Auto 集成配置为语音卫星设备，这样小爱录到的声音就会走这个管道。

---

## 第五步：让小爱闭嘴（12:00-13:30）

**[旁白]**：最后一步很关键——不让小爱自己理解语义，只让它传声音。

**[画面]**：米家 APP 操作录屏
1. 打开米家 APP → 小爱音箱
2. 小爱训练 → 添加训练计划
3. 用户说：`*`（星号，代表任何话）
4. 小爱回复：留空（不说话）
5. 执行设备：选择 Home Assistant

**[旁白]**：这样设置后，你说什么小爱都不自己处理了，全部转发到 HA。

## 常见翻车 tips（14:30-结束）

**[旁白]**：这几个坑我帮你踩过了：

1. **小爱说"没学会这个技能"** → 米家训练计划没配好
2. **Claude 不回** → 检查 API Key 和网络
3. **场景找不到** → 去 HA → 设置 → 实体，搜 scene.，看米家场景有没有同步过来
4. **小爱不播报** → TTS 没配好或小爱音量关了
