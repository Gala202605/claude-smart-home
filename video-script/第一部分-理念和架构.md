# 视频第一集：小爱很笨？用 Claude 让它变聪明！

**时长**：5-8 分钟
**风格**：轻松、痛点共鸣、展示效果

---

## 开场（0:00-0:30）

**[画面]**：对着小爱音箱说话
```
你：小爱同学，帮我关掉客厅灯然后把空调调到26度再放首周杰伦的歌
小爱：对不起，小爱没有学会这个技能（或只做了第一个）
```

**[旁白]**：是不是觉得小爱音箱特别笨？稍微复杂点的话就听不懂，复合指令基本做不了，稍微绕一点的表述就懵了。

**[画面]**：展示本项目的效果
```
你：小爱同学，我准备睡觉了
（小爱沉默1-2秒）
小爱：已关闭客厅灯、电视，空调已设为睡眠模式。晚安～
```

**[旁白]**：但如果把小爱的脑子换成 Claude，效果就完全不一样了。

---

## 为什么会这样（0:30-1:30）

**[画面]**：对比图
```
左边：小爱大脑 → 规则匹配，死板
右边：Claude大脑 → 理解意图 → 匹配你配好的场景
```

**[旁白]**：小爱的问题是它的"大脑"停留在规则匹配层面。你说的每个字都要跟它预设的技能模板完全匹配才行。

**[画面]**：示意图
```
你的话 → 小爱(听不懂) → 放弃
你的话 → HA → Claude(理解意图) → 找到匹配的场景 → 触发执行
```

**[旁白]**：而 Claude 有真正的语言理解和推理能力。你说"准备睡觉了"，它知道去触发你已经在米家里配好的"睡眠模式"场景——场景里要关什么灯、调什么空调，都是你在米家 APP 里自己设的。

**[旁白]**：重点——**Claude 不做指令拆解，不自己发明"睡觉要做哪几件事"**。它只负责听懂你的话，找到匹配的场景，然后触发它。你在米家里配了什么场景，它就能听懂什么。

而且最重要的是——Claude 保留了它所有的通用推理能力。它不光能触发场景，还能算电费、翻译、讲冷笑话。

---

## 两套方案（1:30-2:30）

**[画面]**：卡片式对比

```
方案一：零成本（今天就能做）
小爱音箱 → Home Assistant → Claude
💰 成本：0元（用已有设备）
🕐 时间：15分钟配置

方案二：专属硬件（效果更好）
树莓派 + ReSpeaker 麦克风阵列 → Claude
💰 成本：约 600 元
🕐 时间：1-2 天搭建
```

**[旁白]**：我准备了两套方案。方案一不需要买任何东西，用你手头的小爱音箱就能搞定。方案二我自己做一个专属的 Claude 语音终端。

这期先讲原理，后面两期一步步教你怎么搭。

---

## 核心原理动画（2:30-4:30）

**[动画]**：流程图逐帧出现

```
方案一流程：
你说话 → 小爱收音 → HA(Whisper转文字) → Claude(找匹配场景)
                                                ↓
小爱播报 ← HA(Edge TTS朗读) ← 触发场景(scene.turn_on)
```

**[旁白]**：关键点——小爱只做麦克风和喇叭，Claude 只做匹配和触发。你在米家配了什么，它就触发什么。

```
方案二流程：
你说话 → ReSpeaker阵列收音 → 树莓派(唤醒+转文字) → Claude(找匹配场景)
                                                         ↓
音箱播报 ← 树莓派(TTS合成) ← 触发场景(scene.turn_on)
```
