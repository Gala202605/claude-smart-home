1
装 Docker Desktop（免费的容器工具）
打开 docker.com/products/docker-desktop，下载 Mac 版，拖到 Applications，双击打开。
等右上角小鲸鱼图标变绿。
2
装 Home Assistant（智能家居平台）
打开 Mac 自带的「终端」（启动台里搜"终端"），粘贴下面这行，回车：
docker run -d --name homeassistant --restart unless-stopped --privileged -p 8123:8123 -v /opt/ha/config:/config ghcr.io/home-assistant/home-assistant:stable 等它跑完，浏览器打开 http://localhost:8123 能看到 HA 界面就行。
3
接入小爱音箱到 HA
HACS 安装 Xiaomi Miot Auto 集成。
HA → 设置 → 设备与服务 → 添加集成 → 搜 "Xiaomi" → 扫码登录米家账号。
登录后，你家的灯、空调、窗帘会自动同步到 HA。
4
装上 Claude 智能大脑
先在终端执行以下三行（一行一行粘，每行回车）：
cd /opt/ha/config && mkdir -p custom_components git clone git@github.com:Gala202605/claude-smart-home.git /tmp/csh cp -r /tmp/csh/way1-ha-assist/custom_components/claude_conversation . 然后在 configuration.yaml 末尾加上： claude_conversation:
api_key: "sk-ant-你的密钥" 最后执行 docker restart homeassistant 重启。
5
配置语音管道，开始使用
浏览器打开 http://localhost:8123，初始设置完后：
设置 → 语音助手 → Assist Pipeline → 新建：
语音转文字 选 Wyoming Whisper
对话代理 选 Claude Smart Home（你刚装的）
文字转语音 选 Edge TTS（中文女声）
保存，设为默认。然后对着小爱说：
"关灯、关窗帘、明天天气怎么样"
✅ Claude 自动拆成 3 件事，全部执行并播报。
